## 動画生成AIで何を比較するか

文章から映像を生成する **Text-to-Video**、画像を動かす **Image-to-Video**、既存素材の修正・延長・変換では、適切なサービスが異なる。単純に「一番きれいな動画を作れるAI」だけを選ぶと、実際の制作工程で使いづらい可能性がある。

## 無料と有料の差を確認する表

| 項目 | 質問 |
| --- | --- |
| 利用枠 | 初回だけか、毎月回復するか、追加購入可能か |
| 生成条件 | 秒数、解像度、縦横比、フレームレート、モデル制限 |
| 修正 | 動画の延長、再生成、部分編集、参照画像の保持 |
| 出力 | 透かし、ダウンロード形式、最大サイズ |
| 業務利用 | 生成物の商用利用、アップロード素材の権利、公開範囲 |
| データ | 入力素材の保存期間、学習利用、削除方法、組織向け管理 |
| 運用 | 同時処理、待ち時間、API、請求書、サポート |

無料でも商用利用可能なサービスと、課金しないと商用利用できないサービスがある。「有料だから全部許される」わけでもないので、規約を個別に確認する。

## 採用できた素材1本あたりの費用

たとえば1本の短い広告素材の候補を10回生成し、そのうち2本が採用可能なら、採用素材1本あたり5回分の生成を要したことになる。

**試算の考え方**：

```text
生成単価 = 月額料金または消費クレジットを、同条件の生成費用へ換算
採用素材の実質費用
  = （全生成費用 + 追加編集費用） / 採用できた素材数
```

これは比較のための概念式。実際の課金方式、繰越クレジット、編集時間の人件費、失敗生成の扱いはサービスごとに異なる。

「月額が安い」「無料生成回数が多い」だけでなく、**何回修正したら使える動画になるか**を測りたい。

## 公平な比較実験のやり方

1. 同じ目的・同じ構図・同じ長さをできる範囲で指定。
2. 同じ参照画像を使う場合は、アップロード権限と各規約を確認。
3. 各サービスで生成回数と設定（モデル名・秒数・解像度）を記録。
4. **品質**：動きの自然さ、文字・UIの正確さ、破綻、色・構図。
5. **制作性**：修正のしやすさ、待ち時間、書き出し、透かし。
6. **法務・運用**：商用利用、人物・ロゴ、素材の権利、入力データの扱い。
7. 主観評価と実測コストを分けて結論を出す。

## 広告での使い分け

実在しないUIをAIに作らせて、あたかも実際の機能のように見せることは避けたい。ソフトウェアの操作説明ならOBSなどで本物の画面を収録し、AIは背景や演出用素材として用いるほうが適切な場合がある。
